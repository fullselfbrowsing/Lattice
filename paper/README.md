# Lattice papers

`main.tex` is the Information Systems Frontiers draft. It uses the article class with author-year citations (`natbib`, `apalike`) and a design-science frame. Springer Nature's `sn-jnl` class is not vendored: the template download page is script-rendered, so this build could not fetch `sn-jnl.cls`. Before submission, port the body into `\documentclass[pdflatex,sn-apa]{sn-jnl}`.

`ieee/main.tex` is the IEEE conference version. It vendors `IEEEtran.cls` because the build image does not ship that class. Text uses `mathptmx` rather than `newtx`, which is also absent from the image.

`numbers.tex`, `eval-tables.tex`, and `Fig2.png`–`Fig4.png` are generated by `eval/scripts/06-report.py`. Do not type numbers into the narrative by hand. `bench/results.json` is generated by `pnpm bench:receipts` and fills the IEEE benchmark table.

```sh
cd paper && make
cd ieee && make
```
